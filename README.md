# 錯題本

個人錯題本網頁：算錯的題目用手機拍照或上傳檔案，收進自己的錯題本，隨時複習。

李向宇老師製作

## 功能

- 每題分開存「題目」和「答案」，兩邊都能拍照或上傳檔案（照片、圖片、PDF），答案也可以直接打字
- 答案預設藏起來，先自己重算，點一下才看得到
- 可標章節（108 課綱 14 單元）、錯因（計算錯誤／觀念不清／看錯題目／粗心／其他）、訂正筆記
- 首頁「複習一下」把待訂正的題目一題一題拿出來複習，答對就標記已訂正
- 依章節、訂正狀態篩選，關鍵字搜尋
- 手機優先，深藍＋金線筆記本風格

## 資料存在哪裡

題目與照片只存在你這個瀏覽器裡，不會上傳到任何伺服器，每個人的錯題本都是獨立的。

換手機或換瀏覽器前，先用頁面下方的「匯出備份」存成檔案，到新裝置再「匯入備份」，就能把題目帶著走。

## 自己部署一份

1. Fork 這個 repo
2. 在 repo 設定裡開啟 GitHub Pages（Source 選 Deploy from a branch，分支選 main）
3. 打開 `https://你的帳號.github.io/mistake-notebook/` 就能用
